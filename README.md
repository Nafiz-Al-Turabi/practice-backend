# Chat Server

Express + PostgreSQL starter structure.

## Folder Structure

- src/config: database and app configuration
- src/controllers: request handlers
- src/middlewares: reusable middleware
- src/routes: route definitions
- src/services: business logic
- src/models: database models or query helpers

## Setup

1. Install dependencies with `npm install`
2. Copy `.env.example` to `.env`
3. Update the PostgreSQL connection string
4. Run `npm run dev`# practice-backend
